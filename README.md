# Suzy Says

A cheerful DVD host gives instructions in a familiar house. Your job is to listen for the words that make an instruction count, then decide how to respond. Suzy Says, by MOONBIT, turns that simple listening task into a short first-person horror game.

This independent fan and guide website explains the original game, offers two focused Guides and introduces eight other unsettling experiences. It is not operated by MOONBIT or the other game creators. The original Suzy Says is a Windows release. The home page loads its configured player; that frame has not been verified by direct play as an edition of Suzy Says.

## Make each instruction count

The original game's key distinction is whether the host says the qualifying words “Suzy says.” Read the whole instruction, identify its action and target, and respond to the current task rather than anticipating the next one. The original Windows controls are WASD to move, Space to jump and C to crouch. A different hosted experience can have different controls.

Game pages keep written help separate from the player. They explain starting steps, decisions, common problems and version limits, with videos after the article for players who want to see the game in motion. Webpage Fullscreen expands the player area; Browser Fullscreen requests the browser's display mode. Neither changes a game's rules or input support.

## Two Guides for different moments

- [Suzy Says commands: decide before you move](https://suzysaysgame.site/guides/suzy-says-command-rules): distinguish a qualifying command from an instruction without the required words, match the action to the target and check input focus when a response fails.
- [Your first Suzy Says session](https://suzysaysgame.site/guides/suzy-says-first-run): choose the original Windows edition, prepare controls and subtitles, and recognize the opening DVD activity before the first command. It stops where command practice begins.

Both Guides leave ending routes alone. They explain their version scope rather than promising that the home-page frame matches the original release.

## Eight games with different decisions

- [Assessment Examination](https://suzysaysgame.site/games/assessment-examination): inspect portraits and make Trust or Threat judgments as the examination changes around you.
- [Please Answer Carefully](https://suzysaysgame.site/games/please-answer-carefully): work through an unsettling questionnaire, paying attention to the difference between checkboxes, single choices and sliders.
- [last seen online](https://suzysaysgame.site/games/last-seen-online): explore a stranger's desktop, manage overlapping windows and follow clues between files and applications.
- [The Open House](https://suzysaysgame.site/games/the-open-house): navigate a virtual property tour and notice when the presentation stops behaving like an ordinary listing.
- [Bad Ben](https://suzysaysgame.site/games/bad-ben): move through a house viewed through security cameras, adjusting direction as the viewpoint changes.
- [the uncle who works for nintendo](https://suzysaysgame.site/games/uncle-nintendo): choose passages in an interactive story and pay attention to time, conversation and the consequences of a choice.
- [Exhibit of Sorrows](https://suzysaysgame.site/games/exhibit-of-sorrows): interact with a series of clown exhibits and watch how familiar display actions become more troubling.
- [Burger & Frights](https://suzysaysgame.site/games/burger-frights): steer a bicycle through a dark forest route and follow changing visual cues without losing the road.

## Questions before starting

**Is this the official Suzy Says website?** No. It is an independent fan and guide website. The original game belongs to MOONBIT. The current home-page frame uses its configured address and is not verified by direct play as the original game.

**Has every embedded game been tested with real input?** No. The writing uses creator information and reviewed gameplay recordings. Embedded-game input testing has not been completed, so availability, controls and device compatibility are not guaranteed.

**Can I use a phone for the original Suzy Says?** The original release is for Windows. A phone opening this website does not make that release touch-compatible. Check the controls and platform of the particular experience you open.

**Will the videos reveal later scenes?** They can. Read the nearby spoiler warning before playing a recording. The two written Guides focus on command decisions and first-run preparation rather than ending routes.

**Do I need an account?** No. This website has no account, comment, payment or subscription feature. Embedded game and video hosts can receive browser requests and have their own storage behavior.

**How can I report an error?** Email support@suzysaysgame.site with the affected page, game version and specific statement or behavior. Avoid sending passwords, payment details or unrelated personal information.
